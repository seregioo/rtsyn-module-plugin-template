# RTSyn Module Plugin Template

Template files used by `rtsyn-module-generator`.

Files keep their final source extensions so editors provide normal syntax
highlighting. Replacement tokens use identifier-style names such as:

```c
_rtsyn_module_slug_
_rtsyn_module_upper_
_rtsyn_port_descriptors_
```

The generator renders this tree into a concrete RTSyn plugin module.
